# AutoCRM para Android e iOS

Execute os comandos a partir da raiz do monorepo. Use `npm ci` e depois `npm run mobile`, `npm run android` ou `npm run ios`. As rotas `/oficina` e `/motorista` usam o pacote de acesso compartilhado. A rota `/demo` é uma simulação isolada.

Veja o [guia da raiz](../../README.md) para pré-requisitos, configuração do Supabase e exportação. Os identificadores nativos de exemplo precisam ser definidos antes da distribuição.
